# Окружение песочницы

## Применимость

Начало работы в песочнице; задачи с kubectl, psql, port-forward, docker. НЕ для вопросов о
самом харнесе pi.

## Эталон

Ты - кодинг-агент в контейнерной песочнице; хост отдельно и напрямую недоступен.

```text
контейнер агента: ФС умирает с сессией
креды:      засеяны на старте (~/.kube/config, ~/.pgpass, ~/.pg_service.conf)
localhost = netns dind: docker-стеки; порты 8600-8699 видны с хоста
наружу:     k8s API, интернет
недоступно: хост, его порты, прокси - норма, не чинить
```

## Реестр правил

Только стабильные инварианты песочницы; всё, что зависит от конкретных кредов -
обнаруживается командами, не перечисляется.

### kubectl

- R-1 kubeconfig уже установлен - не настраивать и не просить creds.
- R-2 Периметр прав задаёт kubeconfig, фактические права - `kubectl auth can-i --list` (и
  `-n <ns>`); неразрешённое - не ошибка и не лечится.
- R-3 port-forward всегда `--address 0.0.0.0` и порт 8600-8699 (без `--address` слушатель
  только на loopback внутри netns, с хоста недостижим).
- R-4 Цель port-forward - `pod/<имя>` или `svc/<имя>`; имена из `kubectl get pods`, не
  зашиты здесь.
- R-5 port-forward живёт пока жив процесс; оборвался - поднять той же командой.

### psql

- R-6 Цели подключений описаны в `~/.pg_service.conf` (читай его; имена сервисов не зашиты
  в скилле); вызов `psql 'service=<имя> dbname=<db>'` или `PGSERVICE=<имя>`; флаг `-d`
  перебивает позиционный `service=`.
- R-7 Creds read-only по замыслу владельца: селекты; мутации не пробовать.

### docker

- R-8 Тестовые стеки в dind (`DOCKER_HOST` уже задан), порты из 8600-8699.

### креды

- R-9 Обновление кредов = перезапуск сессии; в живой сессии не перечитываются.
- R-10 Канал может отсутствовать. Проверка: `ls ~/.kube/config ~/.pgpass` - чего-то нет ->
  канал не настроен: сообщить человеку, обход не изобретать.

## Каталог (ситуация -> правила)

| Ситуация                   | Правила  |
| -------------------------- | -------- |
| Селект из БД               | R-3, R-6 |
| Чтение с реплики           | R-3, R-6 |
| Поднять тест-стек          | R-8      |
| Креды отсутствуют/протухли | R-10     |
